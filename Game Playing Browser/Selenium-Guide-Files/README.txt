DataJobs - dummy site for the Selenium guide (selenium-guide.pdf)

1. Open a terminal in this folder.
2. Run:  python -m http.server 8000
3. Open http://localhost:8000/index.html
4. Run the examples from the guide. They use URL = "http://localhost:8000/index.html".

Files: index.html (main page, Listing 1), style.css, about.html, salaries.html (opens in a new tab),
newsletter.html (shown in the iframe, Listing 2).
